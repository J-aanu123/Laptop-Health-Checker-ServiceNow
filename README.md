# Laptop Health Checker – ServiceNow

## Project Overview

Laptop Health Checker is a custom ServiceNow application developed to monitor laptop health and manage laptop repair requests. It helps track battery health, laptop condition, repair status, and critical issues while automating support activities.

## Key Features

- Laptop health and battery monitoring
- Laptop repair request management
- Health status validation
- Duplicate open repair request prevention
- Automated repair request processing using Flow Designer
- Critical laptop health notifications
- Role-based access using custom roles and ACLs
- Reports and interactive dashboard

## ServiceNow Concepts Used

- App Engine Studio
- Custom Tables and Fields
- Client Scripts
- Business Rules
- Flow Designer
- Notifications
- Roles and ACLs
- Reports
- Dashboards

## Application Roles

- `student_user` – Student-level access
- `it_support` – IT Support-level access
